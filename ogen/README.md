# Hello World API: ogen

The same contract as [`../oapi-codegen`](../oapi-codegen), implemented with
[ogen](https://github.com/ogen-go/ogen). `api/openapi.yaml` is byte-for-byte
identical to the oapi-codegen copy.

## Layout

```
api/openapi.yaml            the contract (keep identical to ../oapi-codegen/api)
api/spec.go                 embeds the YAML into the binary
internal/oas/               GENERATED by ogen: server, client, JSON, validators
internal/handler/           business logic: implements oas.Handler
internal/server/            wiring: RFC 9457 errors (../problem), 404/405, routes
internal/docs/              /openapi.yaml, /openapi.json, /docs, /redoc
cmd/server/                 main: http.Server with timeouts and graceful shutdown
```

There is no `oapi-codegen.yaml`-style config: the flags are on the
`//go:generate` line in `internal/oas/generate.go`. Optional settings
(for example, disabling client generation) go in an `ogen.yml` passed with `--config`.

## How it differs from the oapi-codegen version

- **Validation is generated code.** Parameters and bodies are checked against
  `minLength`, `pattern`, `enum`, required fields and `additionalProperties: false`
  while they are decoded, with no runtime spec and no validation middleware.
- **Optional fields are `OptX` types** (`OptString`, `OptLanguage`) with
  `.Or(default)`, instead of pointers.
- **Each operation returns a sum type** (`GetHelloRes`), which is implemented by
  `*Greeting` and `*Problem`. Returning any type the contract does not allow
  fails to compile.
- **ogen types encode JSON with `go-faster/jx`.** If you encode them with
  `encoding/json`, pass a pointer (see `writeProblem`).
- **A typed client and OpenTelemetry hooks** are generated as well.
- **"Convenient errors":** because every operation declares a `default`
  response, ogen requires a `NewError(ctx, err) *ErrorStatusCode` method on
  the handler and generates the encoding of the `default` response. The
  sample maps `*problem.Problem` there; `WithErrorHandler` only sees
  transport-level failures (decode, validation).

## Run

```bash
go run ./cmd/server -addr :8081
```

Then open http://localhost:8081/docs.
